# Bluesky source — BSKY-JETSTREAM-1

CULT consumes the documented public Jetstream WebSocket stream with collection filters for `app.bsky.feed.post`, `app.bsky.feed.like`, and `app.bsky.feed.repost`. The default public endpoint is configurable. Jetstream provides simplified JSON and a microsecond cursor; reconnect uses a short cursor rewind plus event-hash deduplication so at-least-once replay does not double-count.

Eligible record handling follows the `app.bsky.feed.post` lexicon: original text, reply text, and quote-post text are bucketed separately; a pure repost or like is not an eligible new document. Like/repost strong references and reply/quote references may produce separate behavior events only when the referenced expression-bearing post was observed in the current transient map. Missed/out-of-order subjects remain unresolved rather than being guessed. Deletes remove transient mappings and may emit deletion audit events.

The collector validates, deduplicates, extracts registered expressions, aggregates one-minute windows, checkpoints the cursor, records lag/health, and reconnects with bounded exponential backoff. In live-shadow it may append a behavior tape containing opaque HMAC record/cascade identifiers and expression sets. It persists no handles, profiles, DIDs, or post bodies. Raw text and AT URIs exist only during parsing/transient linkage.

Tests use recorded synthetic protocol fixtures and never require the live service. Live operation is explicit with `CULT_DATA_MODE=live-shadow` and requires PostgreSQL. Bluesky's own Jetstream announcement says the simplified stream is useful for experimentation but may not be appropriate when verified completeness/authenticity is essential to a research study. CULT therefore labels this panel provisional and retains source-health/missingness caveats; an authenticated firehose or licensed research source remains a future validation path. Source references: [Bluesky Jetstream announcement](https://docs.bsky.app/blog/jetstream), [post/reply/quote records](https://docs.bsky.app/docs/advanced-guides/posts), and the [like strong-reference example](https://docs.bsky.app/blog/lexicon-resolution).
