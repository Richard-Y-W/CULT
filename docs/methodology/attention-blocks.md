# Attention blocks

`ATTENTION_BLOCK` identifies an extreme expression-behavior state after sufficient baseline history. Candidate inputs are amplification, propagation, breadth, concentration, and quality. Thresholds are configurable and versioned; percentile or robust-z thresholds are preferred after empirical calibration.

An attention block is a signal-tape event. It is never translated directly into an order or reference count. Agents receive it after latency and apply their own response function. In synthetic demos the thresholds are scenario fixtures, so no empirical significance is claimed.
