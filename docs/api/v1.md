# API v1

Base URL: `http://localhost:4100/api/v1`. JSON errors include a human-readable `error`; validation errors include typed issues.

| Method | Route                           | Purpose                                                         |
| ------ | ------------------------------- | --------------------------------------------------------------- |
| GET    | `/assets`, `/assets/:ticker`    | Market list and detail                                          |
| GET    | `/assets/:ticker/history`       | Reference and market series with events                         |
| GET    | `/assets/:ticker/platforms`     | Latest normalized platform observations                         |
| GET    | `/assets/:ticker/semantics`     | Semantic history                                                |
| GET    | `/indexes`, `/indexes/:ticker`  | Cultural indexes and history                                    |
| GET    | `/portfolio`, `/orders`         | Authenticated demo account state                                |
| POST   | `/orders`                       | Validated BUY, SELL, SHORT, or COVER                            |
| GET    | `/leaderboard`                  | Time-weighted-return ranking                                    |
| GET    | `/analytics/pair?a=CRY&b=SKULL` | Pair ratio, spread, correlation, z-score                        |
| GET    | `/analytics/correlation`        | 90-day Pearson matrix                                           |
| POST   | `/backtests`                    | Run deterministic momentum example                              |
| GET    | `/events`, `/research`          | Synthetic events and read-only research                         |
| GET    | `/data/status`                  | Active data mode, source health, lag, methodology, and coverage |

Asset detail includes `referenceMetrics`: mode/status, raw and Jeffreys-smoothed prevalence, velocity/acceleration/breadth/persistence when available, source health, quality components, and methodology/source/registry versions. Missing live metrics are `null`, never synthetic substitutions.

`GET /health` sits outside the versioned base and reports data mode. The local cookie session is intentionally development-only.

## Experimental research routes

- `GET /research/series?ticker=CRY` — timestamped series plus provenance.
- `GET /research/factors` — broad market return, dispersion, breadth, concentration, and entropy.
- `GET /research/correlation?a=CRY&b=SKULL` — Pearson and Spearman diagnostics.
- `GET /research/pairs?a=CRY&b=SKULL` — log-spread hedge ratio and conditional half-life diagnostic.
- `GET /research/price-discovery?ticker=CRY` — market-premium regression.

Synthetic results are labelled experimental and are not empirical findings. These endpoints establish no causal interpretation.
