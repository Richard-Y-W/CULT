# Signal tape

The signal tape is derived from the expression tape and never feeds back into reference measurement. `CULT-BEHAVIOR-1` events include prevalence, amplification and propagation shocks, concentration warnings, attention blocks, and source degradation. Each record carries event time, expression, value, standardized score where available, and methodology version.

An attention block is information, not an order. Agents may ignore, down-weight, or trade it after their configured feed and processing latency. No signal can be delivered before its input event is received.
