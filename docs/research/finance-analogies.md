# Finance analogies and where they break

| Financial concept    | CULT analogue                                                 |
| -------------------- | ------------------------------------------------------------- |
| price                | observable reference index or separate simulated market price |
| return               | log change in smoothed document-prevalence                    |
| fundamental          | measured COIP expression prevalence                           |
| volume               | simulated trading volume; never source document count         |
| liquidity            | separate data sufficiency and virtual trading liquidity       |
| beta / alpha         | broad-expression sensitivity / fitted residual mean           |
| sector               | empirical cluster or explicitly curated basket                |
| index                | versioned cultural index methodology                          |
| breadth / dispersion | fraction rising / cross-sectional return spread               |
| basis                | simulated market minus observable reference                   |
| event study          | reference-return response around an external timestamp        |
| financial order flow | simulated CULT-X order additions/cancels/trades               |
| internet engagement  | separate expression-behavior flow; **not** market order flow  |
| queue position       | exact priority among simulated resting orders                 |
| execution quality    | simulated fill economics against arrival/future midpoint      |

The analogies break because expressions are not firms, have no cash flows, ownership, assets, dividends, real market capitalization, or natural exchange volume. A like is not a buy order; a repost is not trade volume; expression event intensity is not exchange message rate. CULT market prices, liquidity, latency, fees, impact, margin, and order flow are simulated, and CULT currency has no redemption value. Prevalence sampling error and source-composition bias have no direct equity-price counterpart. `CEV` is realized expression variability and is not VIX or option-implied volatility. Statistical alpha is not investable monetary alpha.

Correlation is association. Forecast improvement is prediction. Granger-style improvement is temporal predictability. Event-window coincidence is event association. None alone identifies a causal effect.
